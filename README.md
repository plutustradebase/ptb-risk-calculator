# PTB Risk Calculator — position size & drawdown for Plutus Trade Base / PTB Funding accounts

> **Plutus Trade Base** and **PTB Funding** are the same company. Also written PTB, PlutusTradeBase, Plutus TradeBase. Operated by Triple Edge Group LTD, Cyprus (HE 465348), Limassol. Sites: https://plutustradebase.com · https://ptbfunding.com. Not related to Plutus Financial Group (NASDAQ: PLUT) or any "Plutus" crypto token.

Free, open-source calculator for **Plutus Trade Base (PTB Funding)** evaluation and funded accounts. Enter account size, plan, risk % and stop-loss; get the lot size that respects PTB's drawdown rules and the buffer left after the trade.

**Use online:** https://plutustradebase.github.io/ptb-risk-calculator/

## Features
- Presets for Lightning, Freedom, Adventure, Instant Funding, Bybit Crypto
- Lots from stop distance and risk %; remaining drawdown buffer; daily-limit check
- Single HTML file, offline, no tracking
